# ベンチマーク仕様

## 目的

同一Datasetに対する複数の追跡手法と，同一Case・Scenarioに対する複数のカメラ配置手法を公平かつ再現可能に比較する．Phase 0では評価枠組みのみを定め，指標の最終式，閾値，採否基準は実験計画のレビュー後に確定する．

## 評価単位

- **Case**：地形，土地被覆，遮蔽，牧場境界などの環境単位．
- **Scenario**：Case上の鹿，行動，カメラ，時間，seedの条件．
- **Dataset**：ScenarioをSimulatorで実行して保存した観測と評価用Ground Truth．
- **Run**：固定Datasetと手法設定の組合せによる推定および評価結果．

比較時はDataset IDを固定し，手法が同じ観測系列を受け取るようにする．配置法の比較ではScenarioとseed群を固定し，提案された配置だけを変える．

## 追跡評価

個体単位の診断では，時刻ごとに真値と推定位置の距離行列を作り，Hungarian法で一対一対応する．研究の主評価は群れ単位とし，真の群れ中心と推定群れ中心の2D位置誤差，非観測時間，非観測中の予測成功率を保存する．予測成功率は10 m以内を主結果，5 m・20 m以内を感度確認とする．真値対応付けはEvaluatorでのみ行う．

最大対応距離，欠測の扱い，集計重み，信頼区間は実験計画へ記録する．同一Dataset・同一閾値でないRunを同じランキングへ混在させない．

## 配置評価

初期研究では農場内の2D可視率を配置条件として記録し，可視率，連続非観測時間，群れ中心の予測成功率の関係を比較する．カメラ台数による順位付けとCamera Geometryの最適化は将来拡張である．視認距離，FOV，森林・建物遮蔽，地形遮蔽を評価条件として記録する．

## 評価の妥当性

完全一致，既知の位置ずれ，予測欠落，観測欠損時間の延長を含む統制入力を用意する．既知の劣化に応じて位置誤差が増加し，予測成功率が単調に低下すること，同一条件とseedで同一結果になることを自動テストする．これは評価基盤の内部妥当性と再現性を確認するものであり，実機環境に対する外的妥当性の主張ではない．

Phase 7の対象領域被覆は，鹿の地表・0.75 m・1.5 mの3D可視判定を2Dへ投影して計算可能とする．完全可視，部分可視，不可視，観測点直下の垂直FOV死角，terrain/森林/建物遮蔽を区別する．grid解像度は評価条件へ記録し，鹿の連続座標をgrid中心へ丸めない．

## 再現性

RunにはCase ID，Dataset ID，Scenario設定，アルゴリズム名とversion，全パラメータ，seed，Python・OS・GPU環境，Schema version，開始・終了時刻，成果物checksumを記録する．同一設定とseedで再実行できることを要求し，非決定的GPU処理を使う場合はその旨と許容差を記録する．

## 保存方針

Datasetは`cases/<case_id>/datasets/<dataset_id>/`，Runは`cases/<case_id>/runs/<run_id>/`に保存する．入力設定とmanifestは人が確認できる形式を基本とし，大規模な時系列や配列の形式は実装Phaseで決定する．評価用真値はTracker入力から分離する．
